# 🚀 Astronav Dashboard 🚀

A lightweight, web dashboard which displays real-time space data using official NASA APIs.

##  Features
* **NASA Picture of the Day (APOD):** Displays the daily space picture along with its official explanation and title(it only displays images only if the article has one) 
* **Near-Earth Asteroids:** Fetches real-time data on asteroids passing near Earth today, including estimated diameter, speed, and miss distance.(used Nasa neows to collect realtime data of asteroids)
* **NASA News & Gallery:** Allows users to filter space imagery and articles by topics (Space, Mars, Artemis) with content sorted by date.

## 🛠️ Tech Stack
* **Coding Language:** HTML5, CSS3, JavaScript 
* **APIs Used:** 
  * [NASA APOD API]-(https://api.nasa.gov/)
  * [NASA NeoWs (Near Earth Object Web Service)]-(https://api.nasa.gov/)
  * [NASA Image and Video Library API]-(https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf)

## ⚙️ Setup & Installation
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. *(Optional)* Replace the `apiKey` variable in the script tag with your own official API key from [api.nasa.gov](https://api.nasa.gov/).
